# Архитектура MVP

`src/bot.ts` собирает плагины, scenes и обработчики GramIO в нужном порядке. `src/features/users/` регистрирует Telegram-пользователя. Игровой код находится в `src/features/games/`:

- `handlers/` маршрутизирует команды, кнопки и одношаговые действия;
- `scenes/` ведёт пошаговое создание игры, изменение настроек и пожеланий;
- `service.ts` проверяет права и состояние игры, выполняет игровые сценарии;
- `repository.ts` содержит Drizzle-запросы, PostgreSQL storage для scenes и транзакционную границу;
- `drawing.ts` строит пары без зависимости от Telegram и БД;
- `screens.ts` формирует карточки и клавиатуры из уже загруженных данных;
- `notifications.ts` доставляет сохранённые результаты.

Пошаговый диалог хранится только в `scene_states`: ключ — Telegram ID, значение — полное состояние GramIO scene. Миграция `0002` переносит незавершённые записи `drafts` и удаляет старую таблицу. Сцена держит шаг и ответы, но перед сохранением игрового изменения сервис заново проверяет права и состояние. При создании игры её состояние удаляется в той же транзакции, что создаёт игру и участника. Навигация и `/start` очищают активную сцену.

Игра работает в личном чате. Invite code разрешает запросить вступление, но не даёт права управлять игрой. Изменение состава, пожеланий и жеребьёвка блокируют строку игры. Жеребьёвка выполняется целиком в одной транзакции: lock → состав → проверки → чистый алгоритм → назначения → статус `drawn` → commit. После этого состав и пожелания неизменяемы. Назначение читается только через участие самого дарителя.

Язык интерфейса выбирается по языку Telegram-пользователя: русский для `ru` и аккаунтов без языка, английский для остальных. `users.locale` сохраняет язык для отложенной рассылки; встроенный бюджет переводится при отображении, а пользовательский текст остаётся как введён.

Результаты сохраняются до рассылки. Успешная отправка отмечается в назначении; неотправленные результаты повторяются при запуске бота и обращении участника к `/start`. После сбоя между отправкой и отметкой возможна повторная доставка.
