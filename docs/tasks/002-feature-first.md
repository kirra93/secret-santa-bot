# Разделить игровые обработчики

Источник: [архитектура](../architecture/overview.md).

## Работа

1. Удалить неиспользуемые файлы и зависимости генератора GramIO; вернуть typecheck и lint для всего `src`.
2. Разнести игровой код по `users` и `games`; разделить Telegram-обработчики по пользовательским сценариям, не меняя callback data и схему БД.
3. Добавить короткий JSDoc к транзакционной жеребьёвке, изменению состава, приватному чтению назначения, состоянию ввода и повторной доставке.
4. Проверить сценарий A/B/C, запреты после жеребьёвки, типы, lint и сборку Docker-образа.

## Критерий готовности

Главный обработчик удалён. Каждый игровой сценарий находится в модуле своей функции, правила доступа остались в игровых операциях, а существующий сценарий пользователя проходит без изменения.

## Результат и проверка

Демонстрационные файлы и неиспользуемые зависимости генератора удалены. Игровые операции и GramIO-обработчики разделены по функциям; форматы кнопок и схема БД сохранены. JSDoc добавлен к операциям с важными инвариантами.

Проверены `npx tsc --noEmit`, `npm test`, `npm run lint`, `npm ls --depth=0` и `docker compose build bot`. Интеграционный сценарий проверяет создание, вступление, пожелания, выход и повторное вступление, настройки, жеребьёвку, ограничения доступа и состояния, повторную доставку и удаление игры. Реальная доставка через Telegram не проверялась.
